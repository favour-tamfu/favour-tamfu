### Featured Projects:

*   **[Cadence](https://github.com/favour-tamfu/cadence_app)**: AI-enhanced e-book reader with an in-reader AI companion, offline-first sync and mobile money subscriptions. Around 26,800 lines, 61 automated tests, CI/CD and monitoring. *Flutter, Supabase Edge Functions, Google Gemini, GitHub Actions, Prometheus/Grafana*
*   **[VeriScript](https://github.com/favour-tamfu/veriscript-mobile)**: Bilingual (English/French) document integrity suite with AI content detection, on-device OCR, file conversion and layout-preserving translation. *Flutter, Supabase, Google ML Kit, Cloud Translation*
*   **[Cry-Out](https://github.com/favour-tamfu/Cry-Out)** ([live](https://cry-out.vercel.app)): Anonymous crime and social-issue reporting platform connecting victims to responder organizations, with geospatial heatmaps and PWA support. *React, Node.js, Express, MongoDB, Leaflet*
*   **[idared.org](https://github.com/favour-tamfu/dared)** ([live](https://idared.org)): Production website for a Cameroonian nonprofit, with its own design system, full SEO and a custom deploy pipeline. *Next.js, TypeScript, Tailwind CSS*
*   **[Nkweya & Sons Constructions](https://github.com/favour-tamfu/nkweya-constructions)** ([live](https://favour-tamfu.github.io/nkweya-constructions/)): Bilingual (English/French) website for a civil engineering contractor. *Next.js 15, React 19, next-intl, Tailwind CSS*
*   **[Stock Prediction Model](https://github.com/favour-tamfu/Stock-prediction-model)**: Machine learning pipeline from raw data preprocessing to a regression model. *Python, pandas, scikit-learn*
